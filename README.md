# WebsiteHexo

Source code for [lichye.github.io](https://lichye.github.io), built with [Hexo](https://hexo.io/).

## Local development

```bash
npm ci
npm run server
```

## Build and deploy

```bash
npm run clean
npm run build
npm run deploy
```

The customized Academia theme is vendored in `themes/Academia` so that the complete site can be reproduced from this repository.
